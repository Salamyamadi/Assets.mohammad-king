# Assets.mohammad-king
عملیات و اجرای دستور محمد پادشاه کل دنیا یا همان (محمد امینی) برای ترور و کشتن افرادی که بدونه اجازه انواع دارایی ها و ثروت محمد پادشاه کل دنیا از سال ۱۹۹۵میلادی در برنامه ها و اپلیکیشن های مختلف و پروژه هوش مصنوعی جهانی  به سرقت بردن و تا امروز هر کاری برای پس ندادن دارایی ها به مالک محمد امینی به کد ملی ۲۶۷۹۱۸۷۲۷۱ هر اقدامی حتی ترور انجام داده ان
